## Security Policy

### 1. How to Submit a Report:
Do not open a public GitHub Issue for security vulerabilities.
Publicly disclosing a bug before a fix is available puts all users at risk.
- Preferred Method: Use GitHub Private Vulnerability Reporting.

### 2. What to Include in Your Report:
- To help us reproduce and fix the issue quickly, please include:
- What kind of issue is it? <br>
- Where is it? <br>
- How critical is this? (Low, Medium, High, Critical). <br>
- A summary of what is going on. <br>
- A numbered list of steps to trigger it. <br>
- Screenshots, video, or code snippets. <br>

### 3. Supported versions:
- Only report the latest versions as it is the most important part to report.
