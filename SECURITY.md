## Security Policy

### Supported Versions

Only the latest update is supported.

Version          | Supported          
-----------------| ------------------ 
Beta Release 2   | :white_check_mark: 
Beta Release 1   | :x:                

### Reporting a Vulnerability

1. How to Submit a Report
Do not open a public GitHub Issue for security vulnerabilities. Publicly disclosing a bug before a fix is available puts all users at risk.
- Preferred Method: Use GitHub Private Vulnerability Reporting.

2. What to Include in Your Report
To help us reproduce and fix the issue quickly, please include:
Field               | Description
------------------- | --------------------
Type of Issue       | What kind of issue is it?
Location            | Where is it?
Severity            | How critical is this? (Low, Medium, High, Critical).
Description         | A summary of what is going on.
Steps to Reproduce  | A numbered list of steps to trigger it.
Proof of Concept    | Screenshots, video, or code snippets.
